# Brand Assets Directory

Place Instagram assets here:

## Required files:
- `logo.png` or `logo.jpg` — profile picture from @vangug__
- `hero-bg.jpg` — main hero background image
- `portfolio-1.jpg` through `portfolio-6.jpg` — portfolio project images

## Instructions:
1. Visit https://www.instagram.com/vangug__/
2. Right-click profile picture → Save as `logo.png`
3. Save 6 best posts as `portfolio-1.jpg`, `portfolio-2.jpg`, etc.
4. Save 1 image for hero background as `hero-bg.jpg`

Images will be auto-optimized by Next.js Image component.
